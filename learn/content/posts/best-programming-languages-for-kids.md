"Which programming language should my child learn?" It's one of the first questions parents ask, and the honest answer is that **the best language is the one that matches your child's age and what they want to make**.

A seven-year-old who loves cartoons needs something very different from a fourteen-year-old who wants to build a website for their band. This guide walks through the languages that work best for children, what each is genuinely good for, and how to pick.

## The quick answer

| Age | Best starting point | Why |
|---|---|---|
| 5 to 7 | ScratchJr | Picture blocks, no reading needed |
| 7 to 10 | Scratch | Full block coding, games and animations |
| 10 to 13 | Python (or Scratch then Python) | Readable text code with endless uses |
| 11 and up | HTML, CSS and JavaScript | Build real websites and browser games |
| 10 and up | Lua in Roblox Studio | Motivating for Roblox fans |
| 12 and up | Swift, Java or C# | For specific goals: apps or advanced games |

Read on for what each one is really like.

## Block-based languages (ages 5 to 10)

### ScratchJr (ages 5 to 7)

ScratchJr is a free tablet app where children snap together picture blocks to make characters move, jump, dance and talk. There's almost no reading involved, so it suits children who are still learning to read.

**Good for:** first experiences of cause and effect, sequencing and storytelling.
**Move on when:** they can read comfortably and want more control.

### Scratch (ages 7 to 12)

Scratch, made by the MIT Media Lab, is the most popular first language in the world for good reason. Colourful blocks fit together like puzzle pieces, so there are no spelling mistakes or missing brackets to cause frustration. Yet underneath, Scratch teaches every core programming idea: loops, conditions, variables, events and even clones and lists.

**Good for:** games, animations, interactive stories, and learning to think like a programmer.
**Limitations:** it's designed for learning, not for building professional software, and big projects get hard to organise.

## Text-based languages (ages 10 and up)

### Python

Python is the language we most often recommend as a first text language. Its code reads almost like English, it uses less punctuation than most languages, and it's used by professionals everywhere, especially in data science and artificial intelligence.

```python
for i in range(3):
    print("Hello!")
```

**Good for:** games, automating tasks, maths and science projects, data and AI.
**Watch out for:** indentation (spaces at the start of lines) matters in Python, which trips up beginners for the first week or two.

Start with our [number guessing game](/python-number-guessing-game-for-kids/) or browse [10 Python projects for beginners](/python-projects-for-beginners/).

### JavaScript (with HTML and CSS)

JavaScript is the language of the web. Every interactive website you've ever used runs JavaScript. Children usually learn it together with HTML (the structure of a web page) and CSS (the design).

```js
document.querySelector('button').addEventListener('click', () => {
  alert('You clicked me!');
});
```

**Good for:** websites, browser games, anything you want to share with a link.
**Watch out for:** JavaScript has more quirks and punctuation than Python, so it can feel harder at first. Starting with HTML and CSS gives quick, visible wins. Our explainer on [HTML vs CSS vs JavaScript](/html-css-javascript-explained/) shows how the three fit together.

### Lua (Roblox Studio)

Roblox games are scripted in Luau, a version of Lua. For children who love Roblox, the chance to build their own game is incredibly motivating, and Lua itself is a clean, simple language.

**Good for:** game design, 3D building, and learning events and scripting.
**Watch out for:** much of what they learn is specific to Roblox. It works best alongside a general-purpose language. Our step-by-step guide shows [how to make a Roblox game](/how-to-make-a-roblox-game-for-beginners/).

### Swift (iPhone and iPad apps)

Swift is Apple's language for iPhone, iPad and Mac apps. Apple's free **Swift Playgrounds** app teaches it through puzzles on an iPad or Mac, which makes it surprisingly approachable for children from about 10.

**Good for:** children who dream of making their own iPhone app.
**Watch out for:** building full apps needs a Mac and more advanced skills.

### Java and C#

Java powers many Android apps and is famously used for Minecraft Java Edition mods. C# is the main language of the Unity game engine, used to make many professional games.

**Good for:** teenagers with a clear goal, such as Minecraft mods or Unity games.
**Watch out for:** both are wordier and stricter than Python, so they're usually better as a second language.

## How to choose: three questions

**1. How old is your child, and how comfortable are they reading and typing?**
Under about 9, block coding almost always works best. Typing accurately is a real barrier for young children, and blocks remove it.

**2. What do they want to make?**
Interest beats everything. A child who wants to make games will try harder at a game-focused language than at anything chosen for them.

- Games and animations: Scratch, then Python or Lua
- Websites: HTML, CSS, then JavaScript
- Apps: Swift Playgrounds or MIT App Inventor, then Swift or Java
- AI and data: Python
- Not sure yet: Scratch or Python

**3. What's their experience so far?**
Children who've done a year of Scratch can usually jump straight into Python. Complete beginners aged 12 and up can start with Python directly.

## Does the first language matter much?

Less than most people think. The ideas that make someone a good programmer, such as breaking problems into steps, using loops and variables, and debugging patiently, are the same in every language. Most professional developers know several languages and learned new ones as they needed them.

What really matters is that your child:

- builds things they care about,
- finishes projects, even small ones,
- gets help when they're stuck, before frustration sets in,
- keeps going long enough for it to click.

## A sensible path for most children

1. **Ages 7 to 10:** Scratch, building games and animations.
2. **Ages 10 to 12:** Python basics, plus HTML and CSS for a first website.
3. **Ages 12 to 14:** deeper Python or JavaScript projects, maybe some AI.
4. **Ages 14 and up:** specialise in what they love, whether that's apps, games, web or data, and build a portfolio.

Children who start later can move faster. A motivated 13-year-old often catches up with years of Scratch experience in a few months.

## Frequently asked questions

**What is the easiest programming language for kids?** Scratch is the easiest for most children, because its blocks remove spelling and punctuation errors entirely. For a text language, Python is usually the easiest.

**Should my child learn Python or JavaScript first?** If they want to build websites, start with HTML, CSS and JavaScript. Otherwise Python is usually the gentler first text language. We compare them in detail in [Python vs JavaScript](/python-vs-javascript-which-to-learn-first/).

**Is Scratch a real programming language?** Yes. It's a full programming language with loops, conditions, variables, events and more. It just uses blocks instead of typed text.

**How many hours a week should my child spend coding?** Regular short sessions work better than occasional long ones. One or two focused hours a week, plus time to tinker on their own projects, is a great rhythm for most children.
